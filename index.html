Importar tickets

Sincronización con HaloITSM o carga histórica por CSV

Integración HaloITSM Verificando…

Conexión directa y segura: las credenciales de HaloITSM viven solo en el servidor (Supabase Edge Function), nunca en el navegador. Se sincronizan automáticamente los tickets nuevos, evitando duplicados por folio original.

Aún faltan credenciales por configurar del lado del servidor. Sigue estos pasos:

  1. En HaloITSM: Configuración → Integraciones → HaloITSM API → crea una aplicación con método de autenticación "Client ID and Secret (Services)" y copia el Client ID, Client Secret y la URL de tu instancia.
  2. En tu proyecto de Supabase: Project Settings → Edge Functions → Secrets, agrega estas 4 claves:
    HALO_AUTH_URL = https://tuempresa.haloitsm.com/auth/token HALO_RESOURCE_URL = https://tuempresa.haloitsm.com HALO_CLIENT_ID = (tu client id) HALO_CLIENT_SECRET = (tu client secret)
  3. Vuelve aquí y da clic en "Probar conexión".

Vista previa — así quedarían los tickets al importar

Revisa que tipo, estado, prioridad y cliente se vean correctos antes de confirmar. Se muestran hasta 25 de 0 tickets encontrados.
